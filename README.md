## RISC-V Operating System Kernel

A small but fully functional **multithreaded operating system kernel for the RISC-V architecture**, implemented from scratch using **C, C++, and RISC-V Assembly**.

### Features

- Dynamic memory allocation and deallocation
- Multithreading with thread creation, termination, and context switching
- Semaphore-based thread synchronization
- Preemptive scheduling and time-sharing
- Asynchronous context switching using timer and console interrupts
- System call interface through C API, ABI, and C++ API layers
- Console input/output support
- Low-level handling of RISC-V registers, interrupts, and traps
- Kernel development and debugging using QEMU, GDB, Make, and CLion

### Technologies

**C, C++, RISC-V Assembly, Make, QEMU, GDB**
